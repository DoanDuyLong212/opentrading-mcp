# 10 — Chuỗi 8 Projects (Electron) và cách map sang MCP-server

App gốc: Electron knowledge-base (window + doc list + Q&A + local JSON, IPC constants, mock Q&A citations). P(N+1) starter từ P(N) solution. Mỗi project What You Do + Mechanism là 1 nấc.

## P01 Baseline vs Minimal (L01-L02)

Build shell (window, list, panel, data dir). Chạy 2 lần: prompt-only vs rules-first (AGENTS+CLAUDE+init.sh+feature_list+progress+docs/). Học: cùng model khác harness → reliability order-of-magnitude. Isolate 2 dirs (không branches vì agent thấy sibling), reset evidence về not-started trước strong run.
Map MCP: 1 tool `market.status` chạy prompt-only vs có AGENTS+init+feature_list, so pytest/smoke.

## P02 Readable Workspace (L03-L04)

Thêm import/detail/persistence qua 2 sessions. Starter docs mỏng no handoff vs solution ARCHITECTURE/PRODUCT + handoff + feature_list. Học repo-as-truth, split, proximity.
Map: `src/api/ARCHITECTURE.md`, `src/db/CONSTRAINTS.md`, root AGENTS 80 dòng.

## P03 Multi-Session Continuity (L05-L06)

Chunking/metadata/indexing UI/citation Q&A, one-at-a-time không pass thiếu evidence. Starter tracking sơ vs solution init.sh+handoff+progress+clean-checklist. Học clock-in (đọc progress chạy check) / clock-out, chống rush-finish.
Map: `PROGRESS.md` + `session-handoff.md` cho preset scan đang dở.

## P04 Feedback + Scope (L07-L08)

Thêm logs startup/import/index/error + constraints chống cross-layer, plant bug large-file chunking fail. Starter weak diagnostics/no guard vs solution logger.ts+check-architecture.sh+ARCHITECTURE+fix. Học boundary + executable verify, WIP=1 + verify-feature gate + VCR.
Map: `scripts/check-arch.sh` cấm tool vượt preset, `make verify-feature F=...`.

## P05 Self-Verification + Roles (L09-L10)

Nâng conversation/citation/filter, 3 biến thể giữ feature constant: single-role 1.6/5 vs gen-eval 3.3/5 vs plan-gen-eval+sprint-contract 4.9/5. Học tách maker/checker (+planner), 3-layer no-skip + runtime signals. Evaluator cần 3-5 vòng tuning mới align human.
Map: Maker implement quant tool, Checker pytest/e2e MCP độc lập, contract scope/standards/exclusions.

## P06 Capstone Complete (L11-L12)

Assemble + benchmark + cleanup + ablation (gỡ từng component xem matter). Multi-feature import/index/Q&A/observability/restartable. Starter weak (thiếu list/handoff/checklist/scripts) vs solution full + benchmark.sh+cleanup-scanner+quality+evaluator-rubric. Học observability inside, dual cleanup, grades A-D. Không chỉ session output mà codebase health.
Map: `benchmark.sh` chạy preset matrix, `cleanup-scanner.sh` tìm debug/temp, `quality-document.md` chấm src/.

## P07 First Loop (L13)

Từ P06 state. 3 experiments branches riêng:
- Goal: viết goal.md goal/verify/stop/constraints, baseline manual vs /goal iterate.
- Timer: /loop 10-30m ≥2h đếm found/fixed/false-positive/made-worse/followup.
- Maker-checker: Maker/Checker/state loop-state.md/stop N-pass-max-rounds ≥5 rounds ghi feedback/intervention/ceiling.
Metrics completion/interventions/quality/time/reliability. Học step outside loop.
Map: goal scan market green, timer feed Vietstock, maker-checker tool mới.

## P08 First Graph (L14)

显式 hóa ẩn P07. Prep state.md + 3 branches:
- Explicit: list nodes in/out/agent-vs-code, edges conditional/rollback, state readers/writers, routing if-then, graph.md mermaid+tables, tìm ≥1 implicit edge.
- Parallel fan-out/in: split impl/verify/research, rules + merge standard, worktree isolate, so time/cost/quality.
- Human-in-loop: rollback partial về đúng layer + approval trước merge timeout/auto-reject + interrupt format, ≥2 passes so approval vs verify.
Metrics visibility/localization/coordination/observability/reliability. Học graph là loop đủ phức tạp, biết đáng graph (≥3/5 tiêu chí) hay chỉ script.
